Mechatronics Quiz System

Project Description

The Mechatronics Quiz System is a Python-based application designed to test students' knowledge of Mechatronics Engineering.

Features

- Allows students to select their ND level (ND1 or ND2).
- Displays Mechatronics-related questions.
- Provides multiple-choice answers.
- Checks students' answers.
- Calculates and displays quiz scores.

Programming Language

Python 3

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the command:

python quiz.py
